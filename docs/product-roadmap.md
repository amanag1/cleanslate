# Product roadmap

## Included in MVP
- CSV/XLSX profiling
- Predictable cleanup transformations
- Column-level validation
- CSV export
- Local UI and API
- Optional metadata history

## Candidate next release
- Excel worksheet selection and XLSX output
- Configurable reusable cleaning profiles
- Per-row validation issue export
- HTML quality report download
- Processing history UI
- Better handling for encoding and delimiter detection

## Deliberately deferred
- AI-generated transformations
- Fuzzy matching and ambiguous auto-corrections
- Multi-tenant hosted service
- Cloud file storage
- User accounts and billing

Features should be prioritized from observed customer requests, not added just to increase the feature count.
