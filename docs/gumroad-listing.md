# Gumroad listing draft

## Product name
CleanSlate — CSV & Excel Data Quality Workbench

## Short description
A practical local-first toolkit to profile, clean and validate CSV/Excel datasets with transparent rules and downloadable outputs.

## What is included
- Python source code and FastAPI API
- Streamlit analyst interface
- Dataset profiling and cleanup engine
- Declarative data validation rules
- Optional PostgreSQL processing history
- Docker Compose setup
- Kubernetes Helm starter chart
- Sample customer dataset
- Setup guide, API guide and tests

## Who it is for
Data analysts, operations teams, consultants and Python users who repeatedly receive inconsistent spreadsheet exports.

## Suggested launch positioning
Sell the time saved on repetitive dataset preparation, not the fact that the product uses Python. Show a before-and-after walkthrough using the included sample dataset. Be explicit that this is a local-first utility and list current limitations.
