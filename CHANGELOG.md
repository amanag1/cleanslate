# Changelog

- FastAPI profile and cleanup endpoints

- Deterministic column normalization, whitespace trimming and duplicate removal
- Column-level profiling
- Declarative validation rules
- Optional PostgreSQL processing history
- Streamlit local interface
- Docker Compose and Helm starter chart
- Unit and API test suite
